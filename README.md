# Music Plugins

Каталог VST3 на React и Vite. Поиск, группы по издателям и категориям, фильтр по применению, избранное и таблица «Мастер-цепочка». Тема, избранное и открытые группы сохраняются в браузере.

## Локальный запуск

Требуется Node.js 24.

```sh
npm ci
npm run dev
```

`npm run build` собирает сайт в `dist`. `npm run preview` открывает эту сборку локально. Данные каталога находятся в `src/catalog.json`.

## GitHub Pages

В настройках репозитория выберите **Settings → Pages → Build and deployment → Source → GitHub Actions**. Публикация запускается при обновлении ветки `main` или вручную в **Actions → Deploy to GitHub Pages**. Относительные пути к файлам поддерживают как корневой адрес, так и адрес с именем репозитория.
